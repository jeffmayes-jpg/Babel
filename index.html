Babel

A multilingual text-to-speech application for Windows, with tools for reading text aloud and translating between languages.

Download Babel 2.0.0

Babel supports English, French, Spanish, and Khmer speech, and version 2.0.0 adds a screen for translating to and from additional languages using an internet connection.

Download Babel for Windows

The download opens the latest Babel release on GitHub. On that page, select Babel.v2.0.0.Release.zip under Assets to download the application package.

Features

  • Text-to-speech for English, French, Spanish, and Khmer.
  • Language-appropriate voices for reading text aloud.
  • Translation to and from additional languages with an internet connection.

Getting Babel

Use the download link above to access the release package and its release notes.

Babel is a Windows desktop application. Translation to and from additional languages requires an internet connection.
